Tools: read files with the Read tool and search with Grep and Glob. In the shell, run the test command, the one-file test command ('{{TEST_FILE_CMD}} <test file>'), the code indexer's commands and read-only commands (ls, cat, head, tail, wc, grep, git status, diff, log and show, and similar): they run without a prompt. sed, awk, find, interpreters (node, python), curl and wget are refused, and a refused command stops the pipeline. To read a web page, run '{{FETCH_CMD}} <https-url>', a GET-only fetch from the npm registry, unpkg, jsDelivr or GitHub.
To check one test file, run '{{TEST_FILE_CMD}} <test file>' (the file from the project root) instead of the whole suite.
