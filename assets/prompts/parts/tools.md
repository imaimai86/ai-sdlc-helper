Tools: read files with the Read tool and search with Grep and Glob. Do not use cat, head, tail, sed, awk, grep, find or cd in the shell to read or search: they are refused, and a refused command stops the pipeline.
To check one test file, run '{{TEST_FILE_CMD}} <test file>' (the file from the project root) instead of the whole suite.
